
# Задание

1. Откройте файл DA.csv (ВесИглокожих). Проведите двухфакторный дисперсионный 
	анализ для выявления влияния факторов Грунт и Вид (priming и view), Грунт и 
	Район (priming и region), Грунт и Условия (priming и conditions) на Вес (weight)
	 (3 анализа).
	Опишите полученные результаты.

2. Откройте файл university2.csv. Проведите многомерный дисперсионный анализ 
	для определения зависимости выбора университета (University) от рейтингов: 
	Yslov_educ - условия для получения качественного образования, ранг; 
	Yslov_job - уровень востребованности выпускников работодателями, ранг; 
	Yslov_science - уровень научно-исследовательской деятельности, ранг. 
	Опишите полученные результаты.
