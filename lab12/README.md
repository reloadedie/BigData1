
# Задание

Откройте файл KLaster.csv. Самостоятельно проделайте кластерный анализ для 
	объединения животных в группы по характеристикам: температура, расход энергии, 
	относительная поверхность, масса и количество кислорода в органах: мозг, почки, печень, селезенка, мышцы).
	Перед построением дендрограммы удалите первый столбец таблицы.
	Прокомментируйте полученные результаты.


Есть хороший пример проведения кластерного анализа: https://rpubs.com/AllaT/clust3
