. ## Вероятностные распределения

**Дисциплина:** Введение в анализ больших данных

---

. ## 0. Что такое распределение

**Распределение** случайной величины — функция, задающая вероятность того, что величина примет значение или попадёт в интервал.

**Закон распределения** — связь между значениями и их вероятностями.

Для непрерывных распределений важны:
- **плотность** $f(x)$ (pdf) — «форма» распределения;
- **функция распределения** $F(x) = P(X \le x)$ (cdf);
- **квантили** (ppf) — обратная к cdf.

---

. ## 1. Инструмент: scipy.stats

Объекты распределений: `stats.norm`, `stats.uniform`, `stats.t`.

| Метод | Что делает |
|-------|------------|
| `.rvs(size=n, ...)` | случайная выборка объёма n |
| `.pdf(x)` | плотность в точке x |
| `.cdf(x)` | функция распределения |
| `.ppf(q)` | квантиль уровня q |
| `.mean()`, `.std()` | теоретические моменты |

Параметры: `loc` (сдвиг), `scale` (масштаб), `df` (степени свободы для t).

---

. ## 2. Нормальное распределение

$N(\mu, \sigma)$: симметричное, задаётся средним и стандартным отклонением.

```python
x = stats.norm.rvs(loc=mu, scale=sigma, size=n)   # выборка
stats.norm.pdf(x_grid, loc=mu, scale=sigma)       # плотность
```

Стандартное нормальное — $N(0, 1)$.

---

. ## 3. Равномерное распределение

$U[a, b]$: плотность постоянна на отрезке.

```python
u = stats.uniform.rvs(loc=a, scale=b - a, size=n)
stats.uniform.pdf(x, loc=a, scale=b - a)
```

⚠️ В `stats.uniform` **scale — это длина отрезка** (b − a), а не правая граница.

---

. ## 4. Распределение Стьюдента

$t(df)$: похоже на нормальное, но с более тяжёлыми хвостами. При больших df → N(0, 1).

```python
t = stats.t.rvs(df=df, size=n)
stats.t.pdf(x, df=df)
```

Единственный параметр — число степеней свободы `df`.

---

. ## 5. Визуализация: гистограмма + плотность

```python
plt.hist(sample, bins=30, density=True, alpha=0.7, edgecolor="white")
xs = np.linspace(sample.min() - 2, sample.max() + 2, 300)
plt.plot(xs, stats.<dist>.pdf(xs, ...), color="crimson", lw=2)
```

- `density=True` — нормирует гистограмму (площадь = 1), чтобы её можно было накладывать на pdf.
- Сетка по x (`linspace`/`arange`) нужна только для гладкой кривой.

---

. ## 6. Полезные мелочи

- `np.random.seed(2024)` — воспроизводимость результатов.
- `.std(ddof=1)` — несмещённая оценка sd (n−1 в знаменателе). Теоретическое sd — `.std()`.
- `sample.mean()` ≈ `loc`, `sample.std(ddof=1)` ≈ `scale` — так проверяем, что выборка действительно из нужного распределения.
