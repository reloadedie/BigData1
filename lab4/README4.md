. # Конспект по лабораторной №4
. ## Построение таблиц частот

**Дисциплина:** Введение в анализ больших данных

---

. ## 0. О чём лаба

Есть два массива оценок по 100-балльной шкале (год1 = 52, год2 = 61).
Нужно разбить их на категории по двум системам — 5-балльной и европейской — и построить таблицы частот + графики.

**Что тренируем:**
- `pd.cut` — разбиение чисел на интервалы;
- `value_counts` — абсолютные и относительные частоты;
- `pd.concat` — объединение таблиц;
- столбиковые, stacked и круговые диаграммы.

---

. ## 1. Ключевая функция: `pd.cut`

```python
pd.cut(x, bins=..., labels=..., include_lowest=True)
```

- **bins** — границы интервалов (список или число);
- **labels** — имена категорий (той же длины, что и число интервалов);
- **include_lowest=True** — включить минимальное значение в первый интервал.

⚠️ `pd.cut` по умолчанию **исключает левую границу**. Если диапазон начинается с 0, а левый bin = 0, значение 0 попадёт в `NaN`. Решение: взять левый bin = `-0.1` и/или `include_lowest=True`.

---

. ## 2. Категории в задании

. ### 5-балльная система

| Оценка | Баллы |
|--------|-------|
| 2 | 0..50 |
| 3 | 51..68 |
| 4 | 69..85 |
| 5 | 86..100 |

```python
bins5 = [-0.1, 50, 68, 85, 100]
labels5 = ["2", "3", "4", "5"]
```

. ### Европейская

| Оценка | Баллы |
|--------|-------|
| F | 0..30 |
| FX | 31..50 |
| E | 51..60 |
| D | 61..68 |
| C | 69..85 |
| B | 86..95 |
| A | 96..100 |

```python
binsEU = [-0.1, 30, 50, 60, 68, 85, 95, 100]
labelsEU = ["F", "FX", "E", "D", "C", "B", "A"]
```

---

. ## 3. Абсолютные частоты

```python
tablica1_1 = razbitie1_1.value_counts().sort_index()
```

- `value_counts()` — сколько раз встретилась каждая категория;
- `.sort_index()` — упорядочивает по категориям (у `pd.cut` они ordered, так что порядок правильный).

---

. ## 4. Относительные частоты

```python
rel = counts / len(x)
```

Или сразу: `series.value_counts(normalize=True)`.

Смысл: доля каждой категории от общего числа. Сумма всех относительных частот = 1.

---

. ## 5. Объединение таблиц

```python
matrica1 = pd.concat([tablica1_1, tablica2_1], axis=1,
                     keys=["год1", "год2"]).fillna(0).astype(int)
```

- `axis=1` — склеиваем **по столбцам** (две серии рядом);
- `keys=[...]` — имена столбцов;
- `.fillna(0)` — если в одной серии не было категории, ставим 0;
- `.astype(int)` — превращаем float обратно в int (после concat появляются NaN/float).

. ## 6. Визуализация

. ### Столбиковая диаграмма (barplot)

```python
series.plot(kind="bar", edgecolor="black")
```

Аналог R-функции `barplot()`. Показывает абсолютные частоты по категориям.

. ### Stacked barplot (сравнение двух наборов)

```python
df.plot(kind="bar", stacked=True)
```

Каждый столбец — категория; внутри — доли год1 и год2. Удобно видеть, как меняется структура год к году.

. ### Круговая диаграмма

```python
plt.pie(values, labels=values.index, autopct="%1.1f%%", startangle=90)
```

`autopct` — формат подписи процентов. `startangle=90` — начинать с 12 часов.

---

. ## 7. Что важно не забыть

- Границы категорий должны **покрывать весь диапазон** (0..100). Если оставить пробел — появятся `NaN`.
- `labels` должны быть той же длины, что и число интервалов (`len(bins) - 1`).
- При конкатенации таблиц с разным набором категорий появившиеся `NaN` надо заменить на 0, иначе графики построятся криво.
- `pd.cut` возвращает **Categorical**. Если нужен обычный Series (например, для счётчиков) — `.astype(str)`.

. ## 🧠 Шпаргалка

| Задача | Код |
|--------|-----|
| Разбить на интервалы | `pd.cut(x, bins=..., labels=..., include_lowest=True)` |
| Абсолютные частоты | `s.value_counts().sort_index()` |
| Относительные частоты | `s.value_counts(normalize=True)` или `counts / n` |
| Склеить по столбцам | `pd.concat([a, b], axis=1, keys=[...])` |
| Склеить по строкам | `pd.concat([a, b], axis=0)` |
| Заменить NaN | `.fillna(0)` |
| Barplot | `series.plot(kind="bar")` |
| Stacked | `df.plot(kind="bar", stacked=True)` |
| Круговая | `plt.pie(values, labels=..., autopct="%1.1f%%")` |
| Сетка графиков | `plt.subplots(nrows, ncols)` |
