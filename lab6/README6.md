. ## Построение матрицы корреляции (NMES1988)

**Дисциплина:** Введение в анализ больших данных

---

. ## 0. О чём лаба

Корреляционный анализ на датасете NMES1988 (4406 наблюдений, 12 переменных).

**Что делаем:**
1. Проверка нормальности количественных переменных (Shapiro–Wilk).
2. Спирмен для пары `visits ~ age`.
3. Матрица корреляций + heatmap.
4. Значимость пар с |r| < 0.5: вся выборка, мужчины, женщины.
5. `visits` vs остальные по регионам.

**Количественные переменные:** `visits`, `chronic`, `age`, `school`, `income`. Остальные — факторы.

---

. ## 1. Проверка нормальности: Shapiro–Wilk

```python
W, p = stats.shapiro(x)
```

- **H0:** выборка из нормального распределения.
- p > 0.05 → H0 не отвергается (нет оснований считать распределение ненормальным).
- p ≤ 0.05 → распределение значимо отличается от нормального.

⚠️ При большом n тест «ловит» малейшие отклонения. Поэтому смотрим и на гистограмму.

**Почему это важно:** если данные ненормальны, для корреляции лучше брать **Спирмена**, а не Пирсона.

---

. ## 2. Коэффициент корреляции Спирмена

```python
rho, p = stats.spearmanr(x, y, nan_policy="omit")
```

- **rho** — коэффициент ранговой корреляции, от −1 до +1.
- **p** — уровень значимости.

**Интерпретация |rho|:**
| Значение | Сила связи |
|----------|-----------|
| < 0.3 | слабая |
| 0.3 – 0.5 | средняя |
| > 0.5 | сильная |

**Знак:** `+` — прямая (одно растёт, другое растёт), `−` — обратная.

**Спирмен vs Пирсон:**
- Пирсон — линейная связь, чувствителен к выбросам и требует нормальности.
- Спирмен — ранговая связь, устойчив к выбросам и ненормальности. При ненормальных данных — предпочтительнее.

---

. ## 3. Матрица корреляций

```python
corr = df[quant_cols].corr(method="spearman")
```

- Матрица размера k×k, где k — число переменных.
- На диагонали единицы.
- Симметричная.

**Heatmap:**
```python
sns.heatmap(corr, annot=True, fmt=".2f", cmap="RdYlBu_r", center=0,
            vmin=-1, vmax=1, square=True)
```

- `cmap="RdYlBu_r"` — синий для −1, красный для +1, белый для 0.
- `center=0` — центрирование шкалы.
- `vmin=-1, vmax=1` — фиксированный диапазон.
- `annot=True` — подписывать значения в ячейках.

---

. ## 4. Значимость коэффициентов

Для каждой пары — свой p-value. При α = 0.05:
- p < 0.05 → коэффициент **статистически значим** (связь есть, не случайна).
- p ≥ 0.05 → **не значим** (возможно, связь случайна).

**Важно:** при большом n почти любая связь окажется значимой. Смотри и на **величину** rho, и на p-value.

**По группам** — проверяем устойчивость: если связь сохраняется у мужчин и женщин отдельно, она надёжна.

---

. ## 5. Группировка по фактору

```python
for region in df["region"].dropna().unique():
    sub = df[df["region"] == region]
    rho, p = stats.spearmanr(sub["visits"], sub["chronic"])
```

Идея: считаем корреляции отдельно в каждой группе, сравниваем значения между группами.

Полезно для ответа на вопрос «одинаково ли связь проявляется в разных подгруппах».

---

. ## 6. Как читать результаты по NMES1988

- **visits и chronic** — обычно значимая положительная связь: чем больше хронических болезней, тем чаще визиты.
- **visits и age** — слабая или средняя положительная связь (пожилые чаще ходят к врачу).
- **visits и income** — часто слабая, знак может меняться.
- **chronic и age** — заметная положительная связь.
- **school и income** — обычно положительная.

При группировке по региону значения rho могут отличаться — это показывает, что связь не везде одинакова.

. ## 🧠 Шпаргалка

| Задача | Код |
|--------|-----|
| Shapiro–Wilk | `stats.shapiro(x)` → (W, p) |
| Спирмен (пара) | `stats.spearmanr(x, y, nan_policy="omit")` → (rho, p) |
| Матрица Спирмена | `df[cols].corr(method="spearman")` |
| Heatmap | `sns.heatmap(corr, annot=True, cmap="RdYlBu_r", center=0, vmin=-1, vmax=1)` |
| По группам | цикл по `df["group"].unique()` |
| Сводка по двум факторам | `df.groupby("A")[cols].corr()` или цикл + `pivot` |
