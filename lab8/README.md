
# Задание №8
Подбор вида зависимости между переменными с помощью регрессии

1. Откройте файл данных Osvech.csv.

2. Постройте график зависимости температуры от глубины.

3. Проведите регрессионный анализ для проверки следующих видов
		зависимостей между переменными - температура и глубина:
	а) линейная зависимость(y=a0+a1*x);
	б) полиномиальная зависимость второй степени(y=a0+a1*x+a2*x^2);
	в) логарифмическая зависимость (y=ao*log(x)).
Для каждой модели проведите анализ остатков, рассчитайте значение 
	среднеквадратической ошибки и значение AIC-критерия.
Сравнить полученные результаты попарно с помощью anova.
Какая регрессионная модель больше подходит к данным и почему?
